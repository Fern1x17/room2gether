# Roomie

App de búsqueda de compañeros de piso (Flutter + Supabase).

## Puesta en marcha

1. Instala dependencias: `flutter pub get`
2. Copia `.env.example` a `.env` y rellena tus claves.
3. Ejecuta: `flutter run`

## Estructura

- `CLAUDE.md` — plan del proyecto y reglas (lo lee Claude Code).
- `.claude/skills/` — skills especializadas (esquema BD, UI, testing).
- `.claude/commands/` — slash commands (`/nueva-feature`, `/pre-commit`).
- `docs/` — requisitos, casos de uso, modelo de datos, prototipos.
- `lib/` — código fuente Flutter (feature-first).
