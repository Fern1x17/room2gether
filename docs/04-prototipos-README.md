# Prototipos

Guarda aquí tus prototipos visuales de cómo quieres que quede la app.

- Si tienes un PDF de diseño, ponlo en esta carpeta (ej. `prototipo-v1.pdf`).
- Puedes exportar pantallas de Figma a PDF/PNG y dejarlas aquí.
- Claude Code puede leer estos PDFs/imágenes para guiarse al construir la UI:
  solo dile "mira el prototipo en docs/ y construye la pantalla X según ese diseño".
